# User Stories

## One (Issue #1)

As Alice, I want the video to stay where I paused it when I check my results and come back, so that I don't lose my place in the tutorial.

## Two (Issue #2)

As Alice, I want to download an extraction as a text file, so that I can read it with my screen reader later or keep it for reference.

## Three (Issue #3)

As Alice, I want every button reachable by keyboard and announced clearly by my screen reader, so that I can extract text without a mouse.
